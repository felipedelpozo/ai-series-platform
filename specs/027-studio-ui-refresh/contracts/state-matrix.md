# UI State Matrix

| Surface        | Loading                                             | Empty                                                                 | Error and recovery                                                        | Success / retention                                                            |
| -------------- | --------------------------------------------------- | --------------------------------------------------------------------- | ------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| Series         | List/detail skeleton; pending action label          | Explain how to create first series; prompt selection when list exists | Inline notice with retry for list/detail; mutation error stays in context | Created/updated item refreshes; Bible JSON retained on failure                 |
| Assets         | Gallery skeleton and stable detail region           | Explain that generation/import creates assets                         | Inline retry for list/detail; no false empty on 500                       | Filters remain; selection/status refreshes; delete closes detail               |
| Prompts        | Route skeleton; pending create/editor action        | Explain why templates matter and expose create form                   | Field/context notice and retry where read fails                           | Inputs clear only after successful create; editor values persist on failure    |
| Generations    | List skeleton; current job shows live pending state | Explain how to start first generation                                 | Retry list/detail; generation failure shows provider message              | Filters/selection remain; terminal status stops polling including cancelled    |
| Operations     | Layout-shaped skeleton                              | Healthy/zero-cost/failure-free messages per section                   | Page notice with Refresh retry; partial endpoint failure identified       | Refresh preserves structure and announces completion                           |
| Accounts       | Pending auth/workspace labels                       | Signed-out form or explicit no-workspace invitation                   | Context error; credentials/workspace name retained                        | Identity/workspaces update and success is announced                            |
| Settings       | No async load                                       | Honest unavailable/configuration-next-step state                      | Not applicable until settings are wired                                   | No fabricated save success                                                     |
| Episode Studio | Scene rail, preview and inspector skeleton          | Separate no-scenes, no-shot and no-preview states                     | Inline retry for scenes/preview/mutations; prompts retained               | Save/generate/voice/QA/export announce completion; valid partial preview shown |
| Diagnostics    | Existing server-rendered state                      | Preserve existing semantics                                           | Preserve existing development-only handling                               | Preserve existing semantics                                                    |

All client request feedback uses an `aria-live` region. Leaving a route prevents late responses from
producing visible feedback in the abandoned context. Pending mutations disable only the action that
would duplicate the same request unless the whole local form is unsafe to edit.
